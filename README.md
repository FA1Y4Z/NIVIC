NIVIC

O NIVIC é um sistema de organização financeira desenvolvido em dupla durante nossos estudos de programação.

A proposta é criar uma aplicação full stack para ajudar no controle de receitas, despesas e metas financeiras.

Tecnologias

Backend

- Java
- Maven
- MariaDB
- JDBC

Frontend

- HTML
- CSS
- JavaScript

Sobre o projeto

O NIVIC está sendo desenvolvido como parte do nosso aprendizado em desenvolvimento de software, passando por conceitos de programação orientada a objetos, banco de dados, backend e frontend.

Estamos construindo o sistema por etapas, aplicando na prática os conceitos que aprendemos durante o desenvolvimento.

A aplicação ainda está em desenvolvimento e novas funcionalidades e tecnologias serão adicionadas conforme o projeto evolui.

Status

Em desenvolvimento.
